MULTIMODAL AGENT / VIDEO PIPELINE 2025.11 — 2026.02

Ivy

教师教学视频 Agent & HOFTC 结构化生产流水线

将教师的一句话意图通过“三问澄清”转化为 HOFTC 课程结构，按内容特征路由至程序化动画、Unreal 物理仿真或生成式视频服务，并自动合成可交付课程。

负责工作：对话式需求澄清、严格 JSON Schema 结构化中间层、多模态视频工具路由、TTS 与 FFmpeg 异步合成流水线。
实现内容：设计 Timeout/Retry、并发限制、TTS Fallback (ElevenLabs → EdgeTTS) 与本地向量资产复用，保证生成高稳定性。
HOFTC 课程结构 程序化代码动画 Unreal 渲染 FFmpeg 合成 本地向量检索
AI 3D ASSETS / UE5 RUNTIME 2025.02 — 2025.09

Prompt2Life

AI 3D 角色与世界生成平台（UE5 运行时可交互）

从文本或图片生成 3D 角色模型，自动完成骨骼与动画绑定，再在 UE5 运行时动态加载——最终能走、能跑、能自由探索。

负责工作：生成资产处理、骨骼动画绑定、UE5 运行时模型流式加载，以及 Explorer/Create 场景编辑器开发。
实现内容：打通“AI 生成—场景编辑—运行时加载—自由交互”完整链路，支持资产库拖拽、变换、撤销/重做及天气/时间预览。
文本/图片生成 3D 骨骼动画绑定 UE5 Runtime 加载 运行时场景编辑
QUEST 3 MR / INDUSTRIAL DIGITAL TWIN 2025.05 — 2026.05

ROEDefense

Quest 3 工业数字孪生与维修操作训练系统

结合 Quest 3 混合现实扫描与点云重建，把现场 1:1 三维模型作为维修前后的数字化资产，并将物理喷枪传感器遥测数据与模型精准绑定。

负责工作：Quest/OpenXR 应用开发、GLB/PLY/3DGS 重建产物在 UE5 运行时的动态加载、空间锚点对齐与 BLE/WebSocket 遥测。
实现内容：解决三维扫描点云处理、云端异步任务轮询、缓存恢复及温度/压力/流量数据实时驱动的仿真与训练回放。
Quest 3 MR 3DGS / PLY 重建 空间锚点对齐 BLE/WebSocket 遥测
UE5 ARPG / AI-NATIVE TESTING 2025.08 — 2026.08

AoK

UE5 多人 ARPG 游戏 ＆ UnrealMCP 自动测修

重度 ARPG 战斗系统（GAS 技能、投射物、受击霸体、Boss AI），并探索借助 UnrealMCP、日志与客户端感知让 AI 自主测试与修复复杂玩法。

负责工作：基于 GAS (Gameplay Ability System) 实现复杂技能/属性，使用 Behavior Tree 构建怪物机制，组织对象池与战斗逻辑。
实现内容：搭建确定性触发的测试场景，让 AI 读日志、看截图、分析 PIE 结果，实现“AI 写代码 → 运行测试 → 自动定位修复”的工作流。
UE5 / C++ GAS 技能体系 Behavior Tree AI UnrealMCP AI 自主感知测试
UE5 CHAOS / PHYSICS & OPTIMIZATION 2025.12 — 2026.06

Karen

UE5 商场物理破坏解压游戏与深度性能优化

第三人称商场大破坏解压游戏。重点在于大规模 Chaos Geometry Collection 破碎、火/水/电/爆炸物理连锁与极高帧率下的性能平衡。

负责工作：破坏机制与连锁反馈、碎片生命周期管理、Static Mesh Proxy 代理替换、分档 Tick Manager 与可视化性能监控。
实现内容：通过碎片清理、代理替换和分档更新，减少物理计算与 Tick 开销。
Chaos 几何破坏 碎片代理网络 分档 Tick 优化 Automation Test
